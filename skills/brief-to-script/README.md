# brief-to-script

Turn a rough content brief, topic, notes or outline into one editable spoken-word script.

## What it does

- Establishes the audience, message, format, tone and constraints.
- Chooses a simple narrative structure.
- Drafts for the ear rather than the page.
- Returns review notes and unresolved questions.

## Boundary

It stops after the script. It does not create a storyboard, visual direction, artwork, audio or finished video.

## Install

```bash
npx skills@latest add brensterbaz/Skills-Bible --skill=brief-to-script
```

## Example request

> Turn these notes into a 60-second spoken-word script for small-business owners. Keep the tone plain and practical, and do not invent performance claims.

## Safety

The skill is instruction-only and contains no executable scripts. Review [`SKILL.md`](SKILL.md) and your agent’s permissions before use.
