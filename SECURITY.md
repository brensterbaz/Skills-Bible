# Security

## What this repository contains

The repository currently contains instruction-only `SKILL.md` files and explanatory Markdown. It does not contain executable scripts, package-install hooks, compiled binaries, secrets or credentials.

## Before running a skill

- Read the complete `SKILL.md`.
- Check which files, tools, accounts and network services your agent can access.
- Start in a clean branch or recoverable working directory.
- Keep publishing, uploads, purchases and other external actions behind explicit approval.
- Review generated claims and outputs before using them publicly.

Public source makes a skill inspectable; it does not guarantee the behaviour of every agent, tool or future version.

## Reporting a concern

Open a GitHub issue without including private data, credentials or vulnerable customer information. For a sensitive report, use GitHub’s private vulnerability-reporting feature if it is enabled for the repository.
