# script-to-storyboard

Turn an approved or working spoken-word script into a scene-by-scene narrative storyboard.

## What it does

- Reads the complete script before dividing it.
- Finds changes in narrative purpose.
- Maps every spoken line to a scene and an on-screen subject.
- Checks that no wording disappears between script and storyboard.

## Boundary

It plans the story, not the art direction. It does not generate images, audio, animation or finished video.

## Install

```bash
npx skills@latest add brensterbaz/Skills-Bible --skill=script-to-storyboard
```

## Example request

> Map this approved voiceover into a vertical-video storyboard. Keep the wording verbatim and give every scene one narrative job.

## Safety

The skill is instruction-only and contains no executable scripts. Review [`SKILL.md`](SKILL.md) and your agent’s permissions before use.
