# storyboard-to-visual-direction

Turn an approved narrative storyboard into one coherent visual-design system and specific direction for every scene.

## What it does

- Establishes a single visual point of view.
- Defines colour, typography, materials, composition and motion behaviour.
- Gives each scene a specific treatment without losing sequence-wide continuity.
- Flags weak or unsupported visual ideas for review.

## Boundary

It creates the visual-design brief, not the final generation prompts. It does not generate media, audio, animation or a finished video.
